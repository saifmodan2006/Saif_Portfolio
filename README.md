# Saif Modan — AI Developer & Computer Engineer Portfolio

Personal portfolio website of **Saif Modan**, showcasing projects in AI Video Generation, Computer Vision, Full-Stack Python development, and Data Analytics.

---

## Key Features
- **Editorial Modern Aesthetic**: Clean typography inspired by modern minimal editorial design.
- **AI Video Generation Showcase**: High-impact commercial brand video (`Madhav_Chilli_Powder.mp4`) with sound toggle and strict download protection.
- **Interactive "Ask Saif AI" Assistant**: Built-in interactive AI assistant answering visitor inquiries about skills, projects, and contact info.
- **Real-Time Header Clock Widget**: Live IST clock and date display.
- **Project Filter Showcase**: Multi-category filter system (All Projects, AI & Video, Data & Analytics, Web & Cloud).
- **Interactive Experience Accordions**: Enterprise simulations for Tata Group and Deloitte Australia.
- **Dedicated Contact System**: Direct messaging interface with Gmail SMTP backend integration.
- **SEO & Google Rich Snippets**: Integrated Schema.org VideoObject and Person JSON-LD structured data.

---

## Tech Stack
- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom Design System), JavaScript (ES6+)
- **Backend / SMTP**: Python, HTTP Server, Gmail SMTP
- **AI & Tools**: Generative AI, Video Diffusion, Prompt Engineering, OpenCV, FastAPI, Flask, React.js, Pandas, NumPy, Power BI
